# Nagi docs

Nagi is Not Artificial General Intelligence. It is a meta-learning framework
in plain Python: it learns how to learn, and you teach it with your own data
and code.

- [Overview](overview.md): what Nagi is, what it is not, and the ideas
  behind it.
- [Getting started](getting-started.md): install it, teach it, talk to it.

- [Reasoning](reasoning.md): facts, rules and proofs.
- [Code mode](code-mode.md): the programs that responses and learners run.
- [Plugins](plugins.md): your own modules, learners and curricula.

Inside Nagi:
